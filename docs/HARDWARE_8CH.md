# 8 路版本硬件设计说明 (4 x ADS1220)

> 本文对应固件默认配置 `ADS1220_CHIP_COUNT = 4`（8 路）。
> 备份：16 片/32 路的老版本完整副本在 `_backup/16ch_<时间戳>/`。

---

## 0. 结论先说

| 问题 | 结论 |
| --- | --- |
| 8 路能不能做过来？ | **能，而且轻松很多**。引脚占用从 24 个降到 16 个，还多出 ~19 个空闲 IO |
| 还需要逻辑门吗？ | **不需要**。4 片各占一根 DRDY 直接进 MCU，74HC30/74HC132 全部删掉 |
| 要不要四层板？ | **建议四层**（理由见第 5 节）。二层板在 ≤90 SPS 也能用，但必须守布局规则 |
| 能不能先只贴 2 片？ | **能**，改一个宏重新编译即可，而且固件会自己识别出只焊了 2 片 |
| 协议要改吗？ | **不用**。永远是 32 个槽位，没接的槽位填 NaN |

## 1. STM32F103C8T6 (LQFP48) 引脚分配 —— 8 路 / 4 片

| 引脚 | 功能 | 方向 | 说明 |
| --- | --- | --- | --- |
| PA5 | SPI1_SCK | 输出 | 4.5 MHz（ADS1220 上限约 6.67 MHz，留 48% 余量） |
| PA6 | SPI1_MISO | 输入 | **建议加 100 kΩ 下拉到 GND**（见第 4 节） |
| PA7 | SPI1_MOSI | 输出 | |
| PA9 | USART1_TX | 输出 | 115200 / 460800 |
| PA10 | USART1_RX | 输入 | |
| PA13 | SWDIO | — | 调试口，必须保留 |
| PA14 | SWCLK | — | 调试口，必须保留 |
| **PA0** | DRDY0 | 输入 | ADS1220 #0 数据就绪（低有效，MCU 内部上拉） |
| **PA1** | DRDY1 | 输入 | #1 |
| **PA2** | DRDY2 | 输入 | #2 |
| **PA3** | DRDY3 | 输入 | #3 |
| **PB0** | CS0 | 输出 | #0 片选（低有效，初始高） |
| **PB1** | CS1 | 输出 | #1 |
| **PB2** | CS2 | 输出 | #2 |
| **PB3** | CS3 | 输出 | #3 ⚠️ 原为 JTDO，固件已关 JTAG（保留 SWD） |
| PD0 / PD1 | OSC_IN / OSC_OUT | — | 8 MHz 晶振 → PLL×9 = 72 MHz |
| NRST | 复位 | — | 建议 100 nF 到地 + 10 kΩ 上拉 |
| BOOT0 | 启动模式 | — | 10 kΩ 下拉到地 |
| VDDA | 模拟电源 | 电源 | 磁珠 + 100 nF + 1 µF，与 VDD 同源 |

**空闲 IO（约 19 个，留给扩展/按键/LED/第二路串口）**：
`PA4, PA8, PA11, PA12, PA15, PB4..PB15, PC13, PC14, PC15`

### 想扩到 8 片（16 路）时

| 用途 | 追加引脚 |
| --- | --- |
| CS4..CS7 | PB4, PB5, PB6, PB7（PB4 原为 NJTRST，同样靠关 JTAG 释放） |
| DRDY4..DRDY7 | PA4, PA8, PA11, PA12（都在 GPIOA，一次 `HAL_GPIO_Init` 配完） |

改 `board_config.h` 的 `ADS1220_DRDY_MAX_CHIP` 和 `ADS1220_DRDY_PIN()`、以及
`spi_driver.c` 里 DRDY 的初始化掩码即可。你现在的计划是"两块 8 路板各用一个串口"，
那连这个都不用动。

## 2. 相对 16 片版本，硬件上简化了什么

| 项 | 16 片老版本 | 8 路新版本 |
| --- | --- | --- |
| 片选 | PB0..PB15（16 根） | PB0..PB3（4 根） |
| DRDY | 16 根 → 2×74HC30 + 74HC132 与非合并 → 1 根 | **每片一根，直连 MCU，无逻辑门** |
| DRDY 中断 | EXTI0 + NVIC | 无中断，主循环轮询（每次读一条 IDR） |
| 未贴芯片的 DRDY | 逻辑门输入悬空 → **必须外加 4~8 个上拉电阻** | MCU 内部上拉，**不用外加电阻** |
| 故障定位 | 只知道"有片拉低了"，不知道是哪片 | 状态帧直接给出是哪片没就绪 |

### ⚠️ 顺手修掉的一个老版本隐患

STM32 复位后 SWJ 默认全使能，**PB3(JTDO)/PB4(NJTRST) 被 JTAG 占用，不是普通 IO**。
16 片版本用 PB0..PB15 做片选却没有关 JTAG，所以 CS3/CS4 实际上是不工作的
（现象：第 4、5 片永远读不回来、上电校验一直报失败）。

新版本在 `spi_driver.c` 里加了这一句，SWD 下载调试不受影响：

```c
__HAL_AFIO_REMAP_SWJ_NOJTAG();   /* 关 JTAG, 只留 SWD -> 释放 PA15/PB3/PB4 */
```

## 3. ADS1220 侧连接（信号级）

> 封装引脚号请照数据手册的 Pin Configuration 图落（ADS1220 是 TSSOP-16 / VQFN-16）。
> 下面这张**信号级网表**才是决定板子对不对的部分。
> 数据手册：[TI ADS1220 (SBAS501)](https://www.ti.com/lit/ds/symlink/ads1220.pdf)

四片共用 SPI 总线，各自独立片选与 DRDY：

| ADS1220 信号 | 接到 | 说明 |
| --- | --- | --- |
| SCLK | PA5 | 4 片并联，各串 47 Ω |
| DIN (MOSI) | PA7 | 4 片并联，各串 47 Ω |
| DOUT/DRDY | PA6 (MISO) | 4 片并联；片选为高时该脚高阻，所以能共用 |
| CS | PB0/PB1/PB2/PB3 | **每片一根，不要并联**，各串 47 Ω |
| DRDY | PA0/PA1/PA2/PA3 | **每片一根**，低有效 |
| CLK | DGND | 用内部 4.096 MHz 振荡器，**必须接地** |
| AVDD | 3.3 V 模拟 | 0.1 µF + 1 µF，紧贴引脚 |
| DVDD | 3.3 V 数字 | 0.1 µF + 1 µF，紧贴引脚 |
| AGND / DGND | 地平面 | 两脚都就近打到地平面（数据手册推荐共地） |
| REFP0 / REFN0 | 不用 | 用内部 2.048 V 基准，按手册处理（见下） |
| AIN0 / AIN1 | 热电偶 #(2n) | 差分对，K 型 |
| AIN2 / AIN3 | 热电偶 #(2n+1) | 差分对 |
| 未用的模拟输入 | AVDD 或 (AVDD+AVSS)/2 | ⚠️ 例外：AIN3/REFN1 不能这样接 |
| 未用的数字输入 | DVDD 或 DGND | ⚠️ 例外：CLK 只能接 DGND |
| DRDY（未用时） | 悬空或上拉到 DVDD | 这里每片都用了 |

TI 数据手册 9.1.1 推荐的外围：
- 所有数字线（SCLK/DIN/DOUT/CS/DRDY）串 **47 Ω**（抑制边沿、限流）
- AVDD、DVDD 各 **0.1 µF** 去耦（建议再加 1 µF）
- **CLK 接 DGND**

## 4. 必须注意的几个点（会直接影响测出来的温度）

### 4.1 ⚠️ BCS 断线检测电流 × 串联电阻 = 巨大误差

固件默认 `TC_BCS_ALWAYS_ON = 1`，ADS1220 会往热电偶回路注入 **10 µA** 烧断电流。

$$
\text{附加失调} = 10\,\mu A \times R_{\text{回路}}
$$

| 回路电阻 | 附加失调 | 折合 K 型误差 |
| --- | --- | --- |
| 几 Ω（2 m 偶丝） | 几十 nV | 可忽略 |
| 100 Ω（长补偿导线） | 1 mV | ≈ 24 °C |
| **1 kΩ（加了 RC 输入滤波电阻）** | **10 mV** | **≈ 240 °C** ❌ |

**结论**：8 路板如果要加输入 RC 滤波，三选一：
1. 把 `board_config.h` 的 `TC_BCS_ALWAYS_ON` 改成 `0`（放弃烧断电流检测，靠超量程判开路）；或
2. 串阻取很小（≤10 Ω，此时 10 µA × 10 Ω = 100 nV ≈ 0.0025 °C，可忽略）；或
3. 只在测量窗口之外开 BCS（需要改固件时序）。

> 这是本板最容易踩的坑：不接滤波电阻时一切正常，一加 1 kΩ 电阻温度就整体偏 240 °C。

### 4.2 MISO 加 100 kΩ 下拉

四片共用 MISO。如果某片没焊，读它的时候 MISO 悬空，读回来的数据是随机的。
加一个 **100 kΩ 下拉到 GND**，未贴片位置就会稳定读回 `0x00`，上电回读校验能可靠地
把它判为"不存在的片"，不会出现"没焊的片偶尔校验通过"这种玄学问题。

### 4.3 冷端补偿 = 热设计问题，不是电路问题

固件用 **ADS1220 内部温度传感器**测冷端温度。它测的是**芯片自己的 die 温度**，
所以芯片必须和接线端子处于**同一等温区**：

- 四片 ADS1220 尽量靠近接线端子排，排在端子的同一侧、同一块铜皮上；
- 芯片底下铺铜 + 打散热过孔（thermal via）到地平面，让四片温度一致；
- 避免把 ADS1220 放在发热元件（LDO、DC-DC、MCU）旁边；
- 端子排上每个通道的"铜—热电偶"结点也会产生热电势，同一排端子尽量等温、
  避免风直吹（这比换四层板更影响精度）。

### 4.4 输入保护与共模范围

- 热电偶输入共模必须在 `AVSS-0.1 V ~ AVDD+0.1 V` 之间，长导线建议加 TVS/ESD 管；
- 差分对走线等长、紧贴、包地，不要和 SPI/电源线并行；
- 通道之间留足间距，避免漏电流串扰（10 µA 级别的电流源很敏感）。

### 4.5 电源与去耦

- AVDD/DVDD 同源 3.3 V 也可以，但**每片**都要有独立的 0.1 µF + 1 µF；
- AVDD 走线从 LDO 出来后先经过磁珠/隔离再进模拟区；
- LDO 建议低噪声型（原先选的 TPS7A4901 就很好）。

## 5. 要不要四层板？—— 建议四层

### 为什么建议四层

| 因素 | 说明 |
| --- | --- |
| 信号幅度 | K 型热电偶 ≈ **41 µV/°C**，ADC 有 20 位有效精度，噪声余量很小 |
| 干扰源 | MCU 72 MHz、SPI 4.5 MHz 边沿、8 MHz 晶振都在同一块小板上 |
| 回流路径 | 二层板很难同时保证"模拟地连续"和"数字回流不穿过模拟区" |
| 冷端等温 | 四层板的完整地平面**自带均温作用**，四片芯片温度更一致 → 冷端补偿更准 |
| 成本 | 4 片 ADS1220 本身就 ¥40~120；四层板比二层板只贵 ¥30~80（5 片） |

四层带来的收益（连续地平面、受控回流、模拟/数字天然分区、均温）远超那点差价，
而且能省下大量调试时间。

### 推荐叠层（1.6 mm，总厚任意）

| 层 | 用途 |
| --- | --- |
| L1（顶层） | 模拟前端 + 元件：ADS1220、热电偶输入、RC、去耦 |
| L2 | **完整地平面**（关键：ADS1220 和输入走线正下方必须连续，不许开槽） |
| L3 | 电源面/电源走线（3.3V_A、3.3V_D 分区，或整片 3.3V + 分割） |
| L4（底层） | 全部数字信号：SPI、UART、CS、DRDY、晶振 |

要点：
- 模拟输入走线只在 L1，L2 全程在它下面，不要跨分割；
- SPI/UART/CS 这些"脏"线放 L4，离 L1 的模拟区尽量远；
- 晶振紧贴 MCU，下方 L2 保持完整；
- ADS1220 的 AGND/DGND 就近打孔到 L2（每片至少 4 个孔）。

### 如果坚持用二层板（省钱/快速打样）

在 ≤90 SPS 下二层板也能出可用结果，但必须守这些规则：

1. 底层做成**连续地铺铜**，ADS1220 和输入走线下方**绝对不许有走线割裂**；
2. 模拟区（4 片 ADC + 输入端）和数字区（MCU、晶振、串口）分块，
   两地**单点连接**（或直接共用整片地但在布局上物理分开）；
3. SPI 走线尽量短，且不要从模拟输入下方穿过；
4. 每片去耦电容**贴着引脚**，地端就近打孔；
5. 输入端差分对紧贴走线并用地线包围；
6. 先按 20 SPS + 50/60 Hz 抑制跑（这是默认配置，滤波最强）。

**没有把握就直接四层**——四层板的设计容错率高得多，出问题也容易定位。

## 6. 分步贴装流程（板子一次画好，不用重画）

```
① 画 4 个 ADS1220 焊盘 + 4 路输入端子（含只焊 2 片也能用的走线）
② 只焊 #0/#1 两片  →  board_config.h:  ADS1220_CHIP_COUNT = 2
③ 上电，上位机应该显示 8 路里的前 4 路有数据（另外 4 路不显示）
④ 四路都能正常测温、断线检测正确 → 焊 #2/#3
⑤ board_config.h:  ADS1220_CHIP_COUNT = 4  重新编译下载
⑥ 上位机自动显示 8 路（不用改上位机任何设置）
```

没焊的芯片在固件里是这样被处理的：
- 上电回读校验不通过 → `chip_ok` 对应位为 0，状态帧 `chip_err` 位置 1；
- 采集时**根本不等它的 DRDY**（只等校验通过的片），所以不会每轮超时拖慢采集；
- 它的两个通道温度恒为 NaN → 上位机显示为"断线"（如果那两路还显示的话）。

## 7. 上电后怎么确认板子是好的

| 现象 | 说明 |
| --- | --- |
| 上位机"芯片 OK 位图" = `1111` | 4 片全部通信正常 |
| 位图 = `0011` 且你只焊了 2 片 | 正常（后两片没焊） |
| 位图某位为 0 但芯片已焊 | 查该片 CS/SCLK/DIN/DOUT 是否虚焊、AVDD/DVDD 是否到位 |
| 状态帧 flags 出现"回读校验失败" | 有片没通过校验（多半是没焊或虚焊） |
| 状态帧 flags 出现"有片无DRDY" | 该片在通信但不出数据：查 DRDY 走线、CLK 是否接地 |
| 某一路恒为"断线" | 该路热电偶开路，或端子没接好（不是芯片坏了） |
| 所有通道温度整体偏高/偏低约 240 °C | **回去看 4.1 节的 BCS × 串联电阻问题** |
| 四片温度不一致（通道间冷端差异大） | 冷端等温没做好，见 4.3 节 |

## 8. 固件侧开关速查（都在 `Core/Inc/board_config.h`）

| 宏 | 默认 | 作用 |
| --- | --- | --- |
| `ADS1220_CHIP_COUNT` | `4` | **贴了几片就写几**（2 = 4 路，4 = 8 路，8 = 16 路） |
| `TC_MUX_HOLD_CONVERSIONS` | `1` | 每个通道连续读几次再切 MUX |
| `TC_BCS_ALWAYS_ON` | `1` | 断线检测电流源；加了输入滤波电阻就改 `0` |
| `TC_OFFSET_CAL_ENABLE` | `1` | 上电内部短路失调校准 |
| `TC_STATUS_PUSH_PERIOD_MS` | `5000` | 没命令时每 5 s 主动推一帧状态 |
| `TC_DRDY_SILENT_MS`（main.c） | `1000` | 多久没有"全部就绪"就报 DRDY 静默 |
